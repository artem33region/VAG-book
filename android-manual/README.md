# VW Golf IV & Bora — Android-справочник

Автономное Android-приложение на основе переведённого руководства Haynes.

## Возможности

- 31 тематический раздел;
- поиск по названиям разделов;
- структурированный русский текст вместо постраничного PDF;
- отдельные фотографии и электрические схемы без интернета;
- выделение и копирование текста;
- увеличение иллюстраций жестом и двойным касанием;
- сохранение места чтения внутри статьи.

## Требования

- Android 6.0 (API 23) или новее;
- приложение не распаковывает и не отображает PDF: статьи и изображения находятся
  в автономных ресурсах APK.

## Сборка

Проект использует Android Gradle Plugin 8.5.2, compileSdk 34 и Java 17.

```powershell
gradle :app:assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.
