# VW BCA 1.4 16V — Android-справочник

Отдельное приложение `ru.vagguides.bcamanual`, версия 2.0. Устанавливается рядом
с BFQ и Golf/Bora. Русский справочник работает офлайн; 14 разделов включают
два ремня ГРМ, корпус распредвалов, головку блока, смазку, охлаждение, впуск,
индивидуальные катушки, EGR, опоры, диагностику и моменты затяжки.

Это краткий справочник, составленный по локальному Haynes с отбором строк
для 1,4 л/BCA, а не полный перевод ремонтного руководства. В каждой статье
указаны страницы PDF. Иллюстрации и таблицы оригинала доступны с увеличением;
у фрагментов есть отдельная кнопка открытия полной страницы. Подписи в сканах
остаются на языке оригинала. Непроверенная распиновка блока управления не включена.

Автопроверка обновлений работает при открытии главного экрана, как в остальных
приложениях. Из общего `updates.json` выбирается только `ru.vagguides.bcamanual`.
Загрузка и установка требуют нажатия пользователя; APK проверяется по размеру,
SHA-256, package ID, версии и сертификату.

Для сборки достаточно включённых в git исходников и assets:

```powershell
.\gradlew.bat :app:lintDebug :app:assembleDebug
```

Требуются JDK 17/21 и Android SDK 34. Сборка находится в
`app/build/outputs/apk/debug/app-debug.apk`. Для повторной генерации материалов
из корня репозитория: `python build_bca_content.py`. Нужны локальный исходный
PDF и зависимости `requirements.txt`. Координаты рисунков записаны в
`bca_image_provenance.json`; проверка: `python -m unittest discover -s tests -p test_bca_content.py -v`.
